# Changelog

## 1.0.0 — 2026-10-20

First public release of Codex Glance.

- Five-hour and weekly remaining allowance directly in the macOS menu bar.
- Native Swift + AppKit interface, with English and Chinese menus.
- Automatic refresh every 20 seconds and on usage-update notifications.
- Reset times in the local timezone, manual refresh, reconnect, and stale-data status.
- Optional launch at login through macOS ServiceManagement.
- Universal binary for Apple Silicon and Intel, requiring macOS 13+.
- Source-only repository, MIT license, and automated build/release workflow.

This release is ad-hoc signed and not notarized by Apple.
